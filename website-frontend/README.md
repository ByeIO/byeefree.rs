# 「苹果和梨」——苹果霉心病检测系统
苹果霉心病影响苹果品质，苹果霉心病的无损检测方法对苹果品质有重要的指导意义。激光多普勒测振法在各个领域应用广泛，它在农业领域是一种非破坏性的手段，可以来检测水果的内在品质。针对传统检测过程复杂，检测成本高等问题，本软件实现了一种基于激光多普勒测振法的苹果霉心病检测方法。

## 检测原理
### 苹果霉心病简介
苹果霉心病是一种真菌性病害，果实表面几乎无法发觉。因此在生长过程中，该病害几乎不表现出任何病征，甚至在采摘、贮存和销售期间，苹果的外表大多看起来正常，只有在食用时，才会发现果实内部存在病变。苹果霉心病的发病率大概在40%以上。

### 基于激光多普勒测振法的苹果霉心病检测方法
1. 信号采集，利用搭建的激光多普勒测振检测系统采集苹果的振动信号。
2. 数据集的构建，采集的振动信号经过希尔伯特-黄变换(HHT)、Wigner-Ville分布和小波变换处理后转化为时频图像，分别制作成三种不同的数据集。
3. 原始残差网络模型的设计，利用处理后的数据集，使用 ResNet50 网络进行训练。训练过 程中应用 Adam 优化器更新参数，进行数据集的分类识别。小波变换的平均识别率为 83.9%，WVD 的平均识别率为 88.04%，HHT 变换的平均识别率为 89.28%，结合分类准确率、训练和测试速度等，对于 ResNet50 网络模型作为本文的主干网络进行改进。
4. 改进残差神经网络模型设计，为进一步提高模型的性能，研究将 SE 注意力机制模块融入 ResNet50 网络中，并使用支持向量机(SVM)替换网络原有的 Softmax 分类器进行分类。这一改进 旨在增强模型对信号通道和空间特征的关注，提升特征提取能力，从而提高对苹果霉心病的检测精 准度。小波变换的苹果霉心病识别率为 83.34%，WVD 苹果霉心病识别率为 85.65%，HHT 变换苹果 霉心病识别率为 86.67%，小波变换的平均识别率为 86.9%，WVD 苹果霉心病识别率为 90.06%，HHT 变换苹果霉心病识别率为 92.78%。

### 总结
加载采集的声振信号和光谱信号的HHT、WVD、Wavelet变换后的时频图,使用torch调用模型进行预测。
