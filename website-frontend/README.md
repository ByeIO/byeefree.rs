# byeefree指挥系统-前端界面

## 使用说明
```sh
# 测试
cd ./dist
python3 -m http.server 8888
```
访问[http://127.0.0.1:8888/index.html]

## 开发说明
### 目录说明
```sh
- dist文件夹 : 编译产物
- node_modules文件夹 : 依赖库
- src文件夹 : 源码目录
- static文件夹 : 静态资源文件
* build.sh : 编译命令
* index.html : 前端主页
* package.json : 项目配置
* vite.config.js : 打包配置
```

### 代码目录
```sh
- assets文件夹 : 资源文件
- components文件夹 : vue组件
    * HelloWorld.vue : 例程
* App.vue : vue主程序
* main.js : 主程序脚本
* style.css : 样式表
```
